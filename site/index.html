◈ Lighthouse Bridge

Matter · ESP32 / C3 / S3

Lighthouse Bridge WebFlasher

Control up to 16 Valve Lighthouse V2 base stations over Bluetooth. Matter exposes each station as a separate light in your smart home.

Install Lighthouse Bridge

Connect the board with a USB data cable and open this page in Chrome or Edge on a computer.

Keep “Erase device” unchecked to retain settings. For Wi-Fi updates, download the .lhota for your board and upload it in the bridge dashboard.

Choose the exact board. Operation on C3 and S3 boards has yet to be verified on hardware.

Setup and pairing over USB

Read the setup key and address after flashing. Open the dashboard and sign in. To pair a new bridge, get the code under Matter setup and add the bridge in your smart home app. Existing rs-matter updates keep pairings.
