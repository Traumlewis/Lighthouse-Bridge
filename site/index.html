First install or update?

For a first installation on a previously used board, erasing the flash is recommended. This deletes existing settings. For a Bridge update, leave the erase option unchecked to keep your Wi-Fi credentials, access key and station assignments. The installer lets you choose.

After installation

Three steps to your first SLEEP.

  1. 01

    Read your access key

    Open the serial console / “Logs & Console” in the flasher at 115200 baud and briefly press EN/RESET. The ESP32 prints its setup Wi-Fi name and a unique 24-character key. This is your setup and web password.

  2. 02

    Connect to your Wi-Fi

    Connect to Lighthouse-Setup-XXXXXX using your key as the password. Open http://192.168.4.1, select your 2.4 GHz home Wi-Fi and save. Wi-Fi setup runs on the ESP32.

  3. 03

    Assign four stations

    Reconnect to your home Wi-Fi and open the IP address shown in the serial console. Sign in with admin and your key. Discover the four LHB devices, assign them and save. You can then ask Alexa to discover devices.

Prototype · hardware testing pending

The firmware compiles and the interface has been tested with simulated data. BLE and Hue emulation on the Echo Dot 5 still need testing on real devices. “Off” always sends SLEEP, never STANDBY.

Need a hand?

My board does not appear as a USB port

Use a USB data cable and close other serial applications. Install the CH340 driver if needed. Use a browser on a computer; this flasher is not intended for smartphones.

The flasher cannot connect to my ESP32

Hold BOOT, briefly press EN/RESET, then release BOOT once the flasher connects. For a normal restart, press EN/RESET only.

Can I enter my Wi-Fi credentials in the flasher?

This firmware uses its own Wi-Fi setup portal. Improv Serial configuration is not implemented yet. Read your key in the console, then connect to the setup Wi-Fi.

Can I add Pebble control later?

The ESP32 already provides a local API. A Pebble plugin can use it later; the plugin is not part of this prototype yet.

Which language does the installation dialog use?

This page is available in English and German. The ESP Web Tools installation dialog and your browser’s USB port picker use their own language settings and may remain in English.
