A separate prototype using the independent Rust rs-matter stack with the Lighthouse dashboard and Bluetooth worker. Real-device startup, RAM, pairing and multi-station operation still need testing.

Install the complete rs-matter prototype

Configure up to 16 stations as separate lights, with Bluetooth discovery, measured status, personal web password, local API and firmware updates. WLAN, password and assignments are retained. rs-matter requires a new Matter pairing; the earlier stack’s fabric data remains stored for return.

The complete partition table and both 1.875 MiB app slots stay unchanged. Keep “Erase device” unchecked. No filesystem image is uploaded; existing data partitions remain untouched. Use the separate rs-matter .lhota for dashboard updates.

For the original ESP-WROOM-32 / ESP-32S with at least 4 MB flash.
