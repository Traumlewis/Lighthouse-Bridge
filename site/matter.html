Experimental Matter firmware for one base station. Initial hardware operation has been reported; this light-profile update still needs testing.

Prepare with the stable firmware first

Save your Wi-Fi and base-station assignments in the stable Bridge first. This prototype uses only the configured station with the lowest ID. It replaces the running firmware and has no dashboard, local HTTP API or Wi-Fi firmware upload.

Both existing app slots and the NVS addresses stay unchanged. Keep “Erase device” unchecked to retain settings. Return to the stable firmware using the USB WebFlasher, with erasing unchecked again.

For the original ESP-WROOM-32 / ESP-32S with at least 4 MB flash.

Read the Matter setup code over USB

Close the installer first, then read the code. In Alexa, add a Matter device and enter the code manually. Your Echo must support Matter and be on the same home network. This prototype uses test device credentials; pairing may ask you to accept an uncertified device.
