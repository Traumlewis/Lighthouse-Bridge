Read the Matter setup code over USB

After installing, read the key and address here. Open the Bridge dashboard, sign in as admin with the key for the first login, then choose your own password. Under Matter setup you can retrieve the code and open a pairing window. In Alexa, add a Matter device using that code on the same home network. Test device credentials may require accepting an uncertified device.
